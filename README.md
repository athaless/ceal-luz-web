# Sistema CEAL/LUZ

Sistema de gestão do Centro Espírita Amor e Luz.

## Objetivos

- Cadastro de associados
- Cadastro de atendidos
- Gestão de atividades
- Inscrições
- Controle de presença
- Relatórios

## Tecnologias

- React
- TypeScript
- Vite
- Supabase
- PostgreSQL
- Vercel

## Executando

```bash
npm install
npm run dev
```
